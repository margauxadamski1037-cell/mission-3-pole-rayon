Comment ça marche ?

  1. Lis la situation et trouve le code du cadenas.
  2. Tape le code et clique sur « Ouvrir le cadenas ». Bloqué ? Clique sur « Un indice ».
  3. Quand le cadenas s'ouvre, recopie les mots en jaune dans ton carnet.
  4. Ouvre tous les cadenas : ton carnet devient ta fiche à retenir !
